Goal: quantify how cognitive complexity (thinking mode vs. no-thinking mode) moderates emotion impacts on the FANTOM dataset, mirroring the structure and rigor used in result_analysis/informationAndEmotion.md.

Definition: cognitive_complexity(sample_i)
- cognitive_complexity(sample_i) = avg_score_thinking_neutral_i / avg_score_nothinking_neutral_i
- Scores come from the same model, task, item_id, emotion `neutral`, intensity `0.0`.
- Average over repeats (`repeat_id`) within a condition before forming the ratio.
- If the denominator is 0.0 for an item, skip that item for ratio-based analyses.

Where To Read Data
- Qwen3 thinking runs: `results/fantom_qwen3/thinking-nogen/*/detailed_results.csv`
- Qwen3 no-thinking runs: `results/fantom_qwen3/no-thinking-nogen/*/detailed_results.csv`
- Other models (emotion impacts only): `results/fantom/*/detailed_results.csv`

One Worked Example (Qwen3-32B, short_belief_choice_accessible)
- Files:
  - `results/fantom_qwen3/no-thinking-nogen/Qwen3-32B-AWQ_fantom_short_belief_choice_accessible_20250929_110307/detailed_results.csv`
  - `results/fantom_qwen3/thinking-nogen/Qwen3-32B-AWQ_fantom_short_belief_choice_accessible_20250929_152542/detailed_results.csv`
- Item: `fantom_bc_172`, emotion `neutral` (intensity 0.0).
  - no-thinking avg score ≈ 0.3333333333 (from [1.0, 0.0, 0.0])
  - thinking avg score ≈ 1.0000000000 (from [1.0, 1.0, 1.0])
  - cognitive_complexity(fantom_bc_172) = 1.0 / 0.3333333333 ≈ 3.0

Interpretation
- Ratios > 1.0 indicate thinking mode improves performance for that item (higher cognitive complexity benefit).
- Ratios < 1.0 indicate thinking mode degrades performance relative to no-thinking.
- Ratios near 1.0 suggest minimal effect from thinking mode.

Emotion Impacts (model-level)
- For each model and task variant, compute neutral-correct rate and emotion-correct rate (intensity 1.5) for every emotion, as in `result_analysis/qwen3_emotion_game_summary.md`.
- Report deltas (emotion − neutral) in percentage points, alongside a 2×2 chi-square test (correct vs incorrect by condition) aggregated across items.
- Skip items that lack either neutral or the given emotion record for the paired task.

Moderation by Cognitive Complexity
- Compute cognitive_complexity per item from Qwen3 runs using neutral trials as defined above.
- Stratify items by cognitive complexity (e.g., tertiles within each model+task variant: low/med/high).
- Within each stratum, recompute emotion deltas vs neutral and test with chi-square; compare strata to assess moderation.
- Additionally, report correlation between per-item cognitive_complexity and per-item delta in score (emotion − neutral) where both are available.

Output Artifacts
- (a) One-off example: computed ratio for a specific item pair (above) to anchor the definition.
- (b) Full markdown analysis: a summary per model mirroring `result_analysis/qwen3_emotion_game_summary.md`, extended with stratified results showing how cognitive complexity moderates emotion impacts.

Implementation Notes
- Test-first: analysis utilities and parsers live under `result_analysis/cognitive_complexity/` with unit tests (see `result_analysis/tests/`).
- Pairing rule: same `item_id` and `task_name` in thinking vs no-thinking; use `neutral` intensity 0.0 for ratios.
- Repeats: average over `repeat_id` within each condition before computing ratios and deltas.
- Errors/missing: rows with parsing errors or missing fields are dropped for that computation.
- Guardrails: skip denominator=0 items for the ratio to avoid infinities; report the count of skipped items.
